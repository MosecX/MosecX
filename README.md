## 🌌 Sobre mí
Soy un **Frontend Developer** que diseña interfaces premium con intención emocional y claridad visual.  
Trabajo con **React, Next.js, Blade y CSS puro**, cuidando cada detalle con estética inspirada en Apple.

✨ Lo que me define:
- **UI/UX emocional:** diseño para conectar con personas, no solo con pantallas.  
- **Iteración rápida:** pivoto según feedback en tiempo real, sin perder coherencia.  
- **Animaciones fluidas:** **Framer Motion**, **glassmorphism** y transiciones cuidadas.  
- **Colaboración:** humildad, creatividad y precisión a favor del equipo.
